# RESOURCES.md: NASA Space Apps 2026 "Space Mission Design Game" challenge resources

Resources given by the organizers, what each one is, and how we use it. Dated 14 Nov 2026.
Rule: we link to these, we learn from them, we do not copy their text, images, code or game assets. Credit NASA, JPL and the Canadian Space Agency on the About screen. NASA does not endorse non-U.S. Government entities.

## Files kept in `docs/resources/` (for the team and for citing)

| File | What it is | Used for |
| --- | --- | --- |
| `nasa-design-and-develop-science-missions-2025.pdf` | NASA SmallSat Institute webinar slides (26 Mar 2025) | Four mission segments, six-step process, ConOps, measurable requirements, BioNutrients-2 example |
| `nasa-cubesat-101-2017.pdf` | NASA CubeSat Launch Initiative guide (rev. Oct 2017) | CubeSat classes and mass limits, dispensers, licensing, testing, real CubeSat missions |
| `cml-concept-maturity-levels.pdf` | JPL paper on Concept Maturity Levels (2013) | Stage names, 80% checklist rule, margin values |
| (optional) Webb game transcripts, 4 PDFs | Text of the "Build It Yourself" game | How a real-mission match is explained to players |
